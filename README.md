# 🚀 Portfolio Full Stack - Tchango Louis Miller (Byron)

Bienvenue sur le code source de mon portfolio personnel. Ce projet est une vitrine de mes compétences en développement web et mobile, ainsi qu'en création multimédia (design graphique et montage vidéo).

## 🛠️ Stack Technique & Architecture

Ce portfolio est bâti sur les technologies les plus récentes :
- **Framework Core** : [Angular 19](https://angular.dev/) (Standalone Components)
- **Styling** : [Tailwind CSS 4](https://tailwindcss.com/) (JIT Compilation, Design System harmonisé)
- **Routage** : Application multi-pages avec des espaces dédiés pour chaque compétence.
- **Outils de Productivité** : Antigravity AI, Cursor, Zed, Git.

---

## 🧭 Structure du Portfolio

Le portfolio est divisé en trois espaces distincts pour cibler efficacement différentes opportunités :

1. **`/` (Page d'accueil - Développement)** : Portfolio principal orienté Fullstack & Mobile.
2. **`/creative` (Espace caché)** : Portfolio dédié au Design Graphique (Photoshop, Canva) avec une galerie Lightbox.
3. **`/montage` (Espace caché)** : Portfolio dédié au Montage Vidéo (Filmora, AMV) intégrant les vidéos de la chaîne YouTube *BYRON_VDG AMV*.

## 🚀 Développement

Pour lancer le projet localement :

1. **Installation des dépendances**
   ```bash
   npm install
   ```

2. **Lancer le serveur de développement**
   ```bash
   npm start
   ```
   L'application sera disponible sur `http://localhost:4200/`.

3. **Build pour la production**
   ```bash
   npm run build
   ```
